# ⚔️ Clash of Bang - Community Website

Selamat datang di repositori website komunitas **Clash of Bang**! 
Proyek ini adalah platform web interaktif yang dirancang khusus sebagai pusat informasi, diskusi, dan panduan bagi para pemain (komunitas) game Clash of Bang.

## ✨ Fitur Utama
* **Pusat Informasi & Berita:** Update terbaru seputar *event*, *patch notes*, dan pengumuman resmi game.
* **Forum Komunitas:** Ruang interaksi untuk saling berbagi tips, trik, dan strategi antar pemain.
* **Panduan Bermain:** Basis data karakter, *item*, dan peta untuk membantu pemain baru maupun veteran.
* **Desain Responsif:** Tampilan antarmuka (*User Interface*) yang optimal dan nyaman diakses melalui PC maupun perangkat mobile.

## 🛠️ Teknologi yang Digunakan
* HTML5
* CSS3
* JavaScript
